# Contents-page miniatures

Each `<slug>-light.jpg` / `<slug>-dark.jpg` is a screenshot of that lesson's own figure (`.mfw-stage`) in the
tour (the step that shows most of the figure; for the process game the tested wafer), taken in a 1940 × 1180 browser window (spin coating frozen at t = 6 s with `MFW_SPIN_TP`),
cropped by the 1 px plate border and scaled to 800 px wide (JPEG, quality 88). Nothing is drawn by hand.

Regenerate after a figure changes visibly: capture the stages again (Playwright or the preview browser), then
scale them down the same way.
